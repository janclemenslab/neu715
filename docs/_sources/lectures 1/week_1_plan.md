# Week 1 plan

After Week 1, you should be able to read short Python programs without
running them and write or repair a few lines of code.

## Variables and notebook memory

- assign numbers and text to variables;
- use variables in arithmetic;
- trace assignments from top to bottom and predict printed values;
- explain that changing one variable does not automatically recalculate a
  value that was stored earlier; and
- recognise that notebook cells share stored variables and that restarting
  the kernel clears them.

## Conditions

- evaluate comparisons such as `>`, `<`, and `==`;
- recognise that comparisons produce `True` or `False`; and
- read and repair a simple `if`–`else` block, including its colon and
  indentation.

## Lists

- create and read a list;
- retrieve an item with a positive or negative index;
- write a slice, remembering that its stop index is excluded; and
- use `append` to add one item to the end of a list.
