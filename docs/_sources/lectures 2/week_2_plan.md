# Week 2 plan

After Week 2, you should be able to trace short programs that use loops and
functions, write or repair a few lines of code, and make and check simple plots.

## Loops

- generate list positions with `range(len(values))`;
- distinguish an index from the value at that index;
- use a condition inside a loop to count or select values; and
- collect results in a list with `append`.

## Functions

- define and call a function with inputs;
- return a result and use it in later code; and
- distinguish displaying a value with `print` from returning it.

## Dungeon Escape

- apply variables, conditions, and loops to an unfamiliar problem.

## Plotting

- plot paired x and y values in the correct order; and
- label axes and check plotted points against the data.

## Spike detection

- use loops, functions, and plots to inspect a toy voltage recording.
