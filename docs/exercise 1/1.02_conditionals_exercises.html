Conditionals — exercises¶

Work in the answer cells below. Predict an answer before running code, then compare the result with your prediction. The code cells provide starting values, not completed solutions. Deliberately faulty code is shown as text; copy it into an answer cell when you are ready to repair it.

Every complete exercise session has 40 trials. 1 means correct and 0 means incorrect. The exercise training rule is accuracy > 0.66. Because one response is 1/40 = 0.025 of the session, 26/40 = 0.65 does not qualify, whereas 27/40 = 0.675 does.

n_correct / n_trials == 0.65
