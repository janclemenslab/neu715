Exercise 4: RGB to grayscale¶

Load assets/astronaut.png into a new variable called rgb_image using plt.imread. The channel order is red, green, blue; the loaded values lie between 0 and 1.

  1. Predict the shape of a grayscale image with the same height and width.

  2. Create gray_image by averaging over the three colour channels with np.mean and the appropriate axis. Do not use a conversion library or a loop.

  3. Plot it using plt.imshow(gray_image, cmap="gray", vmin=0, vmax=1).

  4. Check the shape and calculate the grayscale value at pixel [100, 200] from its three input values.

  5. Explain why averaging over rows instead would not produce the requested image.

Optional: make a grayscale crop of the same face ROI. This exercise uses a simple arithmetic mean rather than a brightness-weighted conversion.

# Load RGB, reduce the channel axis, plot, and check a pixel.

Exercise 5: isolate flies by thresholding¶

assets/flies_chamber.png is an AI-generated illustrative chamber image, not experimental data. Dark flies are seen from above on a light floor. Use a brightness threshold to isolate their dark bodies.

  1. Load the image with plt.imread and inspect its shape. Plot the original image.

  2. Reuse your approach from Exercise 4 to create a two-dimensional grayscale image. Inspect its minimum and maximum values with np.min and np.max.

  3. Choose a brightness threshold and make a Boolean mask with True for the dark fly pixels and False for the light floor. Decide which comparison direction is needed. Use NumPy, without a loop.

  4. Plot the mask with plt.imshow(fly_mask, cmap="gray", vmin=0, vmax=1). White should mark the selected fly pixels. Compare it with the original image: does the floor disappear, and are the fly bodies retained?

  5. Try a lower and a higher threshold. Describe what is lost or added, then choose the threshold you think best isolates the bodies.

  6. Check that the mask has the same height and width as the original image, with no colour-channel dimension. Inspect one floor pixel and one fly-body pixel to check your selection.

The aim is an approximate body mask. Thin legs and translucent wings may not all be selected. This is a brightness rule, not recognition of a fly.
