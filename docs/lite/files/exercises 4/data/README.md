# Files exercise data

`behavioral_data/` copies the previous course's files exercise data unchanged: six days of initial and final continuous behavioral scores, 40 values per file, for one animal followed across days. Values lie between 0 and 1 and are not binary outcomes. Treat them as inherited teaching data, not newly collected measurements.

The `broken.msg` file is an intentional non-CSV distractor for the file-discovery exercise.
