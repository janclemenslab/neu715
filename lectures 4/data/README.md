# Files lecture data

`demo_sessions/` contains five-trial binary outcomes for two invented animals, before and after training. These are synthetic teaching examples.

`demo_mouse_A.xlsx` has `initial` and `final` sheets containing the mouse A CSV data, with `trial` and `correct` columns. `demo_mouse_A.mat` stores the same arrays as named variables `initial` and `final` in MAT v5 format.
