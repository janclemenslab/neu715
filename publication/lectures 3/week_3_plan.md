# Week 3 plan

## Monday — imports

- Import a module or one of its functions.
- Use an alias and recognise which names an import makes available.
- Diagnose and repair a wrong alias in plotting code.
- Save a function in a `.py` file and call it from a notebook.
- Explain why editing a module may require restarting the kernel.

## Tuesday — arrays and selection

- Convert a list into a NumPy array and reuse indexing and slicing.
- Apply arithmetic to every array value and compute a sum or mean.
- Create a Boolean mask and obtain matching values, counts, and indices.
- Apply the same mask to aligned time and voltage arrays.
- Implement threshold detection with NumPy and compare it with a familiar loop.

## Wednesday — dimensions, images, and audio

- Explain the rows and columns of a two-dimensional array.
- Calculate a summary along the intended axis and check its output shape.
- Load and plot a photograph and explain its rows, columns, and colour channels.
- Slice a rectangular image region and plot the cropped face.
- Load an RGB image and average its colour channels to make a grayscale image.
- Use a brightness threshold to isolate one fly in a chamber image.
- Optional: estimate its position from the mean or median selected-pixel coordinates and plot a dot on the image.
- Check the image dimensions and the value of an individual pixel.
- Load and play a speech recording, convert seconds to sample indices, and crop one sentence.
- Optional: compress sample amplitudes with a sign-preserving log transform and compare playback.
